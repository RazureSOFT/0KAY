# academic-humanizer-zh

检测、打分、诊断并改写「AI 味」中文文本，让论文/学位论文/开题报告/研究报告读起来像真人在写一个真问题：去掉模板结构、空转过渡、空洞结尾、过度工整的节奏和不安全的断言，同时严格保留事实、数据、引用、术语与论证逻辑。用户说「检测AI率」「降AIGC」「润色得像人写的」「去模板腔」时使用。

tags: 论文 学术 润色 降AI AIGC 查重 写作 学位论文 开题 综述 humanize

Source: https://github.com/zkrun/academic-humanizer-zh。英文稿用 `academic-humanizer` 技能。

## 目的

不是靠加随机错误来「骗过检测」，而是删掉可预测的结构、空转的过渡、万能的结论、过分均衡的节奏和不安全的断言，同时保留原意、证据、引用、数据与学科口吻。

适用范围：学位论文、课程论文、期刊/会议论文、文献综述、研究报告、开题与结题材料、摘要/引言/方法/结果/讨论/结论、人文社科/教育/管理/医学/工程/计算机等中文学术文本，以及答辩 PPT 文案。

## 不可违反的规则

1. 保留事实、数据、引用、作者立场、方法与结论，除非用户明确要求删改。
2. 不编造实验、样本、访谈、统计检验、p 值、参考文献、案例细节、田野材料或理论来源。
3. 不强化断言。没有支撑的说法要么补证据指针，要么写得更精确、更有边界。
4. 不要把「AI 模板」换成「反 AI 模板」——反复声明「本文不将……作为结论」同样很假。
5. 不要把每段都写得一样口语。学术文本仍然要正式，只是别那么机械。
6. 跟着学科走：哲学段落、教育学文献综述、工程方法节的语气不能是同一套。

## 打分模型（两轨，不要合并成一个数）

- **表层分（S1–S9，可复现）**：由词表/结构规则决定，每一分都能追溯到一条具体痕迹，是客观下限。
- **语义分（C1–C3，判读）**：抓表层看不到的东西（节奏、口吻、空转推理），**每一分必须引原文证据**，否则不计。

最终给两个结论，并列、不糅在一起：

- **表层分**：按命中项加权（见下）。
- **综合判断**：低 / 中 / 中高 / 高，允许语义压倒表层。两者背离时（典型：表层很低但满篇排比与口号），**以语义为准并明确标注「表层低 / 综合高」**。

档位：0–25 低；26–50 中；51–75 中高；76–100 高。

若环境里有该技能的 `scripts/score.py`，先用它出可复现的表层分（`--json`、`--compare`、`--semantic`、`--report`）；没有就按下面的规则人工计分，并在报告里说明「本分数为规则计分，不等于任何商业检测工具的数字」。

## 表层痕迹（S1–S7）

### S1 模板开头 — 单次 +22
高风险：随着……不断发展 / 在……背景下 / 基于……理论 / 依据……视角 / 针对……问题 / 为提高（探究、解决）…… / 本文围绕……

改法：从一个具体现象、矛盾、研究空白、材料或方法约束起笔；把理论或目的挪到第二句；让段落回答「为什么这个问题在这里重要」，而不是宣布「本文研究什么」。

Before：基于社会建构主义理论，本文探讨课堂互动对学生知识建构的影响。
After：在实际课堂中，学生并不是简单接收教师给出的结论；他们往往是在追问、争论和修正中逐渐形成理解。社会建构主义理论可以解释这种过程，因此本文将课堂互动作为观察学生知识建构的入口。

### S2 排比骨架 — 单次 +20
高风险：首先……其次……再次…… / 一是……二是……三是…… / 理论上……实践上……方法上…… / 宏观……中观……微观…… / 问题、原因、对策三段完全对称。

改法：让最重要的点占更多篇幅，次要的短一些；用因果或对比替代清单节奏；只有论文确实需要编号时才保留。

### S3 空洞结尾 — 每个不同短语 +18，封顶 60
高风险：具有重要意义 / 具有现实意义和理论价值 / 前景广阔 / 提供了新思路 / 开辟了新方向 / 具有重要参考价值 / 对……具有积极作用。

改法：换成具体含义——它到底帮助解释了哪件事？澄清了哪条边界？哪个方法、案例、政策或实践能用？还有什么仍不确定？

### S4 空泛归因 — 每处 +13，封顶 39（附近有引用标记则不计）
高风险：专家认为 / 学者指出 / 研究表明 / 业内普遍认为 / 有观点认为。

改法：要么给出具体引用，要么改成本文自己的分析。
Before：研究表明，社交媒体会显著影响青年政治参与。
After：既有研究多从平台使用频率、政治兴趣和社交网络结构解释青年政治参与，本文关注的是其中更容易被忽视的一点：平台互动是否改变了青年表达政治态度的成本。

### S5 高频学术腔词聚集 — ≥2 个 +12，每多 1 个 +5，封顶 36
高风险：深入探讨 / 系统梳理 / 综合运用 / 有效提升 / 显著提高 / 充分说明 / 不可或缺 / 赋能 / 多维协同 / 完善理论体系 / 构建分析框架 / 推动高质量发展。

改法：不要一律删，只在它们没干活时替换。

### S6 不安全数据语 — 段级 12 + 每个无来源数字 +8，封顶 44
高风险：没有统计检验就说「显著」；没有来源就写 p 值、样本量、回归结果、百分比、访谈人数、实验轮次；证据只支持「说明」时写「验证了」「证明了」。

改法：没有真正收集的数据，就删掉数据断言，改写成设计意图、定性观察、后续数据计划、范围边界或方法模板——不要用反复的免责声明代替。

### S7 升华对比框 — 每处 +8，封顶 20（软信号）
高风险：不是……而是…… / 不仅……而且…… / 不止……而是…… / 不在……而在于…… / 与其说……不如说……

这是中文 AI 腔最隐蔽的反射之一，偶尔用很正常，所以权重低：单独一处不算问题，密集出现或与排比叠加才是问题。只改它在空转、纯粹制造「升华感」的时候。

Before：它不止给一个模糊判断，而是落到具体段落和句子。
After：它会指出具体哪一段、哪一句有问题，对应到哪条痕迹、扣了多少分。

### S8 排比密度 — 段内 ≥4 个同构顿号列 +10
### S9 枚举骨架 — 文档级「第一…第六」「首先…最后」跨段推进 +10（政论/宣传体高发）

## 语义项（C1–C3，你来判，必须引证据）

- **C1 节奏过平滑（0–20）**：句句长而均衡、每段工整收尾、四字排比堆砌、毫无停顿或转折。
- **C2 推理扁平（0–15）**：没有例外、对比、边界、方法理由或作者判断，纯断言或纯抒情。
- **C3 口吻错位（0–10）**：学科/文体口吻被磨成通用腔，口号套话密集。

整篇通读：节奏与口吻常常是文档级特征。表层分很低但满篇口号与四字排比时，综合判断必须反映出来。

## 工作流

### 单段

1. 按 S1–S7 + C1–C3 现场打分（单段可不跑脚本）。
2. **同时**给表层分与综合判断，并点出具体痕迹，不要只说「有点 AI 味」。
3. 给出改写版本，再说新的（更低的）风险。
4. 简短说明改了什么：结构、断言强度、节奏、数据边界或推理链条。

### 整篇

1. 先出检测报告：表层分 + 综合判断（背离时标注）+ 逐段表格 + 最该改的句子。
2. 优先改「中高/高」段落，保留数据、引用、方法；不要动参考文献、目录、图表标题、公式、代码块。
3. 导出**新文件**，绝不覆盖原稿。
4. 再测一遍，给降前/降后对比（表层 + 综合），并列出受保护内容与剩余风险。
5. 如果表层分本来就低、问题主要在语义（节奏/口号），要明说「降的主要是读感，表层数字本就不高」。

不要靠只删触发词来刷分：数字必须下降，但下降要来自结构与推理的真实变化，否则文本只是换了一套反 AI 模板。

## 改写方法

- **从「宣告」转向「推理」**
  Before：为提高研究结论的可靠性，本文采用问卷调查与访谈相结合的方法。
  After：单靠问卷可以覆盖更多样本，但很难解释受访者为什么这样选择。因此，本文在问卷之外补充访谈材料，用来理解几个关键回答背后的原因。
- **打散机械清单**
  Before：本研究具有三方面意义：理论上丰富了相关研究，实践上为政策制定提供参考，方法上提供了新的分析路径。
  After：本研究最直接的价值在于补充了一个常被忽略的解释变量。至于政策层面的启示，还需要放在具体地区和执行条件中讨论，不能简单推出普遍结论。
- **把空泛价值换成具体边界**
  Before：本文结论具有重要的理论意义和现实意义。
  After：本文的结论更适合用来解释样本地区的政策执行差异。若要推广到其他地区，还需要比较财政压力、基层组织结构和公众参与方式是否相近。
- **保持结果精确**：变量、系数、p 值、样本量、置信区间、表号、模型名一律不动；只改过火的解释；因果未建立时把「证明」换成「表明/提示/支持」。
- **文献综述不要写成目录**：按未解决的张力组织，而不是按作者罗列；「研究不足」必须具体。

## 学科适配

- **人文与理论**：保留细微区分，不加例子和理论家，不硬套「结果表明」；可用「可以理解为 / 更接近于 / 这一差异在于」。
- **社科与教育**：保留样本、方法与引用细节；设计不支持时不要暗示因果，用「相关 / 关联 / 可能影响 / 在样本中表现为」。
- **医学与健康**：不改临床结论、风险、剂量、病名和统计结果；避免过度确定的因果语言；伦理、知情同意、纳入排除标准要精确。
- **工程与计算机**：保留组件规格、算法、参数、数据集、基线与指标；区分设计设定与实测性能；没测过的指标删掉，改述功能验证。
- **政策与管理报告**：保留机构口吻，删口号；把「高质量发展 / 赋能 / 协同推进」换成具体机制或实施条件。

## 输出格式

单段：

```
表层分 72%（中高）｜综合判断 中高
触发：S1 模板开头、S4 空泛归因；语义 C1 节奏过平滑（证据：每段都以「由此可见…」工整收尾）
主要问题：1. … 2. …
改后（表层约 20%，综合 低）：> …
变化：把「研究表明」落回本文自己的分析；拆掉开头的「随着…发展」模板。
```

整篇：检测报告（表层 + 综合 + 逐段表 + 最该改的句子）+ 降AI 报告（降前/降后、逐段处理、受保护内容、剩余风险）。

## 交付前自检

- 论证是否被保留？有没有哪句断言变强了？
- 数据、引用、样本、方法有没有被编造？
- 是否既避开了 AI 模板，又没有变成重复的反 AI 声明？
- 文体是否仍属学术，而不是口语聊天？
- 改写段的分数是否真的下降，且没有任何一段比改前更高？如果改了却没降，多半是把一个触发词换成了同类触发词（「第一/第二」换成「一是/二是」都算 S2），回改那一段。
